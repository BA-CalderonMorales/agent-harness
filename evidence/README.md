# Local evidence

Generated recordings and observations belong here only as local, ignored
output. This tracked policy keeps the directory available on a fresh clone;
recording recipes live in `scripts/vhs/` and `scripts/demo/`.

Do not commit transcripts, observer claims, test logs or generated recordings.
Share deliberate, sanitized evidence through CI artifacts or a dated release
attachment. Evaluation runs already use ignored `evals/results/`; retain
host-owned receipts and independent verification there for end-user review.

Historical files removed during the 0.4.1 cleanup remain available in the
[v0.4.0 tree](https://github.com/BA-CalderonMorales/agent-harness/tree/v0.4.0/evidence).
They describe past work and are not proof of current behavior. The README demo
in `docs/demo-tui.gif`, test fixtures and regression tests remain tracked.
