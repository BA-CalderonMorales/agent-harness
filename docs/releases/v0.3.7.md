# Release v0.3.7 - Composition and Navigation Polish

## Overview
Release branch `release/v0.3.7` accumulated 47 commits: the composer and
footer flat redesign, the navigate-first chat contract, the thinking
indicator with the spinning diamond, the config-persistence pipeline, and
the demo stack.

## Changes

### UX
- **Navigate-first chat** — Chat lands in navigate mode with the composer
  blurred; digits, `j/k`, `h/c` own the keyboard until `i` enables typing.
- **Composer and footer redesign** — full-terminal-width layout, solid
  surface block, flush status bar with priority-tier degradation.
- **Thinking indicator** — a one-second quiet beat, then a live header
  (`Agent 14:39 (6.2s) [8 chunks] (thinking ◆)`) with the diamond spinning
  on the same clock; instant responses skip the thinking phase.
- **Quiet system messages** — command results render dim and in-flow, not as
  alert notifications.

### Platform
- Layered settings persistence (project < user < local) with delta writes to
  `~/.agent-harness/settings.json`, encrypted credentials, provider-switch
  keeps model, session model wins at boot.
- Reasoning effort real: `/effort`, `Ctrl+R`, `reasoning_effort` payload.
- Welcome message shows the git root basename, never the full path.

### Tooling
- `scripts/demo/`: VHS tab-tour tape, mock OpenAI-compatible LLM, demo boot
  wrapper; `docs/demo.md` documents re-recording.
- README and docs reorganized in the terminal-jarvis shape; `docs/index.md`
  is the hub.

### Housekeeping
- Removed the stale tracked root-level binary (`bin/agent-harness`, 20MB).

## Migration
No breaking changes.
